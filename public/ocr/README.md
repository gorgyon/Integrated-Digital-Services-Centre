# English OCR language data

`eng.traineddata.gz` is the unmodified open-source English LSTM model from
`@tesseract.js-data/eng@1.0.0/4.0.0_best_int` (Apache-2.0, tessdata).
It is served locally so OCR needs no third-party requests or paid service.
Only public model data is in this folder; applicant files never belong here.
